Fortinux Prime DM OS is a Linux distribution based on Debian 12 that allows you to transform any computer or server into a Layer 2 or 3 switch, router, firewall, or access point—hence the name "Dream Machine" (reminiscent of Ubiquiti’s UDM series). Currently, the following features can be configured:
- VLAN creation and naming
- SVIs and inter-VLAN routing
- Trunk links and "router-on-a-stick" configurations
- Routing (Static [functional], OSPF, EIGRP, and BGP [not fully tested])
- Firewall rules, NAT/PAT overload [functional], static NAT, and port forwarding [not tested]
- Spanning Tree Protocol (STP) [not tested]

Planned features:
- Access Point (AP) functionality (creating WLANs—Layer 2 for integration into VLANs, and Layer 3 to act as a gateway)
- Cable modem functionality (DOCSIS, PPPoE, fiber optic, or coaxial cable support)
- CG-NAT
- VPN server
- IDS/IPS
- User-friendly web-based management interface
